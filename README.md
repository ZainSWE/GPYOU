# GPYOU

GPYOU is an interactive, gemini flash 2.0 AI-powered web app designed to help users choose the ideal graphics card based on their unique needs and budget via answering 4 non-technical questions. Developed during the GDSC Guelph 2025 Hackathon, the project focuses on laying out GPU specifications through a clean, user-friendly interface, perfect for any consumer regardless of experience with said hardware. The project was developed in less than 48 hours and won a category award in "Best User Interface".
